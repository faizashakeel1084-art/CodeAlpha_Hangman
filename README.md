# CodeAlpha_Hangman

Text-based Hangman game in Python (CodeAlpha Python Programming Internship – Task 1).

## Features
- Random word chosen from a list of 5 predefined words
- 6 incorrect guesses allowed
- Input validation (single letters only, no repeated guesses)
- Play-again option

## Concepts used
`random`, `while loop`, `if-else`, `strings`, `lists`, `functions`

## Run
```
python hangman.py
```
